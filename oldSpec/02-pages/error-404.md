# 404 錯誤頁

| 項目 | 內容 |
|------|------|
| 觸發 | 任何不存在的路徑、超出範圍的 Blog 分頁（例 `/blog/page/99`） |
| HTTP 狀態 | 404 |
| Title | 找不到頁面｜聖儀堂中醫診所 |
| 版面 | 獨立簡化版面（`.error-page`），全螢幕置中；**不含** Header、Footer |
| 內容 | 大字「404」（綠色 5rem）、H1「找不到頁面」、說明「你所尋找的頁面可能已移動或不存在。」、按鈕「返回首頁」（深綠膠囊） |

建議新版：保留 Header／Footer 讓使用者可直接導航，並提供服務頁與 Blog 快速連結。
