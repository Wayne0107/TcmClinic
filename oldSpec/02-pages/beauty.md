## 3. 主要表格

### 3.1 面部問題與體質對照（#match）

| 面部表現 | 常見證型 | 調理方向 | 建議組合 |
|---------|---------|---------|---------|
| 黃褐斑、膚色暗沉 | 肝鬱氣滯、血瘀 | 疏肝理氣、活血消斑 | 內服 + 中藥面膜 + 面部刮痧 |
| 皮膚鬆弛、面色萎黃 | 脾胃虛弱、氣血不足 | 健脾益氣、養血 | 內服 + 美顏針 |
| 反覆暗瘡、痤瘡 | 肺經風熱、濕熱、胃熱 | 清肺瀉熱、清熱利濕 | 內服為主 + 溫和外治 |
| 經前必爆的暗瘡 | 肝鬱兼內分泌失調 | 疏肝調衝任 | 內服 + 婦科調理（連 `/gynecology`） |
| 面部浮腫、晨起腫脹 | 脾虛濕重 | 健脾利濕 | 淋巴排毒 + 內服 |
| 黑眼圈、眼袋 | 脾腎不足、血瘀、睡眠不足 | 補益脾腎、活血通絡 | 美顏針 + 面部刮痧 + 內服 |
| 細紋、乾燥缺水 | 腎陰不足、肺燥 | 滋腎養陰、潤燥 | 美顏針 + 潤膚類中藥面膜 |
| 暗瘡印、凹凸洞 | 血瘀兼氣滯 | 活血化瘀、通絡 | 美顏針 + 內服 |
| 敏感泛紅 | 肺胃熱兼屏障受損 | 清熱兼養 | 內服為主，外治須先評估 |
| 脫髮、髮質變差 | 氣血兩虛、腎虛、產後 | 益氣養血、補腎 | 內服 + 頭部經絡疏通 |

> 舊站原文多處把「血瘀」誤植為「血瘦」，見已知問題。

### 3.2 面部經絡理療七步

1. 中醫四診辨體質 → 2. 面部狀態評估 → 3. 清潔卸妝 → 4. 面部肌肉筋膜與經絡疏通 → 5. 淋巴排毒 → 6. 中藥美白倒膜（約 20 分鐘）→ 7. 內服調理中藥（一日）

### 3.3 中藥面膜藥材

白芷（暗沉）、白茯苓（浮腫）、白朮（脾虛濕重）、珍珠粉（敏感泛紅）、薏仁粉（油脂旺盛）、綠豆粉（炎症性暗瘡）、當歸（面色蒼白）。

### 3.4 美顏針效果維持

| 階段 | 頻率 | 維持 |
|------|------|------|
| 單次體驗 | 1 次 | 約 3–7 天 |
| 密集治療期 | 連續 6–10 次，每週 1–2 次 | 約 3–6 個月 |
| 定期保養期 | 每 3–4 週一次 | 可延長至一年以上 |
