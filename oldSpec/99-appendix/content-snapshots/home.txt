TCM GYNECOLOGY
[H2] 中醫婦科：由月經到產後的全週期調理
中醫婦科不只是「調經」，而是循經、孕、產、乳四個階段，追蹤氣血與臟腑的整體狀態。
中醫看女性健康，核心圍繞 腎、肝、脾 三臟與 衝任二脈 。腎主生殖、肝主疏泄藏血、脾主運化生血，任何一環失衡，都可能表現為月經失調、經痛、備孕困難或產後恢復緩慢。因此我們在 {A:中醫婦科 -> /gynecology} 診症時，不會只針對單一症狀處理，而是先辨明體質與病機，再決定用藥先後次序。
[H3] 月經失調與經痛的中醫辨證
月經是女性體質最直接的成績表。經期提前、延後、經量過多或過少、經前乳脹、血塊多、色暗，都各自對應不同病機。臨床上最常見的四類分型如下：
|
| | 常見分型 | 典型表現 | 調理方向
| | 氣血兩虛 | 經量少而色淡、經後疲倦、頭暈心悸、面色蒼白 | 益氣養血，健脾生血
| | 肝鬱氣滯 | 經前乳房脹痛、情緒煩躁、經期不定、血塊較多 | 疏肝解鬱，理氣活血
| | 寒凝血瘀（宮寒） | 經痛遇冷加劇、熱敷後舒緩、血色暗黑有塊、手腳冰冷 | 溫經散寒，活血化瘀
| | 濕熱下注 | 白帶量多色黃、下陰痕癢、口苦、經期延長 | 清熱利濕，調理衝任
調理期間我們一般建議連續跟三個月經週期，因為經期本身就是療效的觀察窗口——經量、色澤、痛感與週期規律性的變化，比任何形容詞都準確。若同時出現皮膚暗瘡、色斑等問題，往往與內分泌相關，可與 {A:中醫美容 -> /beauty} 療程一併規劃。
[H3] 婦女不孕不育與備孕調理
備孕的中醫調理採「分階段用藥」：經後期著重養血滋陰以滋養卵子；排卵期著重疏肝活血以助排卵通暢；經前期著重補腎助陽以穩固黃體；經期則以理氣活血、通暢排出為主。這種按週期節奏調整處方的做法，比長期服用同一條方更貼合生理變化。
- 常見求診情況 ：月經稀少或閉經、多囊卵巢傾向、黃體功能不足、輸卵管術後、卵巢儲備下降、反覆早期流產。
- 配合人工受孕 ：IVF／IUI 取卵前以益氣養血為主，改善子宮血流與內膜環境；移植後轉向補腎固衝、益氣養血，目的是減少子宮敏感與收縮，讓胚胎有較安靜的著床環境。
- 男方同步調理 ：不孕並非女方單方面問題，精液質素、活動力與形態同樣可從補腎益精、清利濕熱方向調理。
中醫調理屬輔助性質，不能取代生殖醫學檢查。若已有西醫療程在進行，請於首次診症時告知用藥與時間表，我們會避開衝突並配合排程。
[H3] 懷孕安胎與孕期不適
安胎的用藥原則是「穩」字為先：以補腎固胎、益氣養血、健脾和胃為主，避免行氣破血與大寒大熱之品。臨床常處理的孕期不適包括妊娠嘔吐、胃脹納差、腰痠腿腫、便秘、失眠與感冒。孕期針灸須嚴格避開禁針穴位，並由註冊中醫師評估後才進行。
[H4] 清胎毒的時機與觀念
民間所謂「清胎毒」，中醫理解為孕晚期清理母體濕熱，一般在懷孕約 32 週後、由中醫師確認體質屬濕熱者才考慮，並非人人適合、也非必做項目。體質偏虛寒者盲目清熱，反而可能損傷脾胃。
[H3] 產後調理與產後扎肚
中醫認為產後「氣血兩虛、百脈空虛」，因此產後首要不是急於收細肚腩，而是先恢復氣血、健運脾胃，再重建腹部筋膜與核心功能。若媽媽本身有怕冷、疲倦、頭暈、胃口差、便秘或腰痠，應先處理整體復原狀態。
|
| | 產後階段 | 調理重點 | 常見處理
| | 產後 0–2 週 | 排出惡露、健脾和胃 | 溫和活血化瘀、飲食調整、充分休息
| | 產後 2–4 週 | 益氣養血、通乳 | 中藥調理、乳少或塞奶處理
| | 產後 4–8 週 | 評估腹直肌分離與子宮復原 | 呼吸、盆底肌與腹橫肌啟動訓練
| | 產後 8 週後 | 體態重建與體重管理 | {A:針灸減肥 -> /slim} 、腹部暖宮、扎肚輔助
[H4] 產後扎肚適合甚麼時候開始
產後扎肚 是以特定手法配合紮身帶，促進氣血運行與代謝，幫助排走水腫、肚風與宿便，並減輕腹腔器官承受的壓力。一般而言，順產媽媽可在產後約 4 星期、剖腹媽媽待傷口癒合約 6 至 8 星期後，經評估再開始。要留意的是，扎肚 不能取代腹直肌修復與盆底肌訓練 ：若腹壁中線空隙明顯，應先做針對性修復，過早高強度捲腹或束腹反而可能加重問題。
[H3] 更年期綜合症調理
潮熱、盜汗、失眠、情緒起伏、心悸與陰道乾澀，中醫多歸於腎陰漸虧、肝陽偏亢、心腎不交。調理方向以滋腎養陰、平肝安神為主，並同步處理睡眠與情緒，因為兩者互為因果。此階段亦是骨質與代謝變化的關鍵期，適合把 {A:中醫養生 -> /#wellness} 習慣正式建立起來。
[H3] 婦科癌症術後的中醫扶正調理
對於乳癌、卵巢癌、子宮體癌等婦科癌症患者，中醫的角色是 扶正培本、減輕治療副作用 ，例如手術後的疲倦乏力、化療後的噁心納差、白細胞偏低、放療後的口乾與皮膚反應，以及長期服用內分泌治療藥物引起的關節痠痛與潮熱。中醫調理屬輔助角色，必須與腫瘤科治療並行，不可自行停用西醫療程；部分中藥與化療、標靶或內分泌藥物存在相互作用，請務必如實告知所有正在服用的藥物。
本網站所載資訊僅供健康教育參考，不構成醫療診斷或治療建議，亦不能取代註冊中醫師或註冊醫生的面診。療程效果因個人體質、病情與依從性而異。如有持續不適，請及早就醫。

TCM BEAUTY
[H2] 中醫美容：面部經絡理療與中藥面膜
皮膚是臟腑的鏡子。中醫美容從氣血、經絡與體質著手，內服外治並行。
很多人勤做護膚卻不見改善，問題往往不在保養品，而在 氣血不通與內分泌失調 。中醫美容的邏輯是：先辨體質、再疏通經絡、最後才是外用。我們的 {A:面部經絡理療 -> /beauty} 包含面部肌肉筋膜調整、淋巴排毒手法、中藥美白倒膜，並配合中醫診症與內服調理中藥。
[H3] 面部經絡理療的完整流程
- 中醫四診 ：望面色、舌象，問睡眠、經期、飲食與壓力，判斷體質分型。
- 面部狀態評估 ：分辨是色素性問題、鬆弛性問題、炎症性問題，抑或水液代謝問題。
- 清潔與卸妝 ：徹底清理表面油脂與化妝品殘留。
- 面部經絡疏通 ：以刮痧與筋膜手法沿經絡由下而上推行，改善面部微循環。
- 淋巴排毒 ：針對顴下、下顎與頸側淋巴走向，紓緩面部浮腫與暗沉。
- 中藥美白倒膜 ：按體質選配面膜粉，敷約 20 分鐘。
- 內服調理 ：開立中藥處方，鞏固療效。
[H3] 中藥面膜的成分與配方邏輯
中藥面膜 並非人人同一配方。常用藥材各有側重：白芷偏於通竅祛風、改善暗沉；白茯苓偏於健脾利濕、適合易浮腫者；珍珠粉偏於安神清熱、常用於敏感泛紅；薏仁粉偏於利濕，適合油脂分泌旺盛者。我們會按你的膚質與體質調整比例，例如乾燥缺水者會減少利濕藥比重，避免越敷越乾。
[H4] 自製中藥面膜要注意甚麼
坊間自製配方常見兩個風險：一是藥粉來源與研磨細度不明，粗粒可能刮傷角質層；二是不辨體質亂用清熱藥，令乾性或敏感肌屏障受損。若要自行嘗試，建議先在耳後小範圍試敷，並避開有傷口、活躍暗瘡感染或正在使用果酸、A 酸的皮膚。
[H3] 美容針（美顏針）能改善哪些問題
美容針 又稱美顏針或面部針灸，使用極幼細的專用針具刺激面部穴位與淺表肌肉層，近乎無痛，少數穴位可能出現輕微酸脹或細小出血點。市場上的稱法以「美顏針」較常見，兩者所指相同。臨床上主要針對：
- 紋路與輪廓 ：抬頭紋、眼紋、魚尾紋、法令紋、輪廓鬆弛。
- 色素問題 ：色斑、雀斑、膚色暗啞不均。
- 炎症與疤痕 ：暗瘡、毛孔粗大、暗瘡後凹凸洞與紅印。
- 水液代謝 ：面部浮腫、眼袋、黑眼圈。
香港市場的美顏針單次收費大致由數百元至一千餘元不等，多以 6 次或 12 次療程套裝計算。療程節奏一般建議初期每週一次，穩定後轉為每兩至四週保養一次。首次進行前，中醫師須面診評估皮膚狀態與體質，不會即日直接施針。
[H3] 療程後護理與不適合人士
療程後 24 小時內建議避免化妝、劇烈運動、桑拿與泳池；若出現細小瘀點，一般數日內自行消退。以下情況不宜進行或須先由醫師評估：面部有開放性傷口或活躍感染、嚴重出血傾向或正服抗凝藥、孕婦、近期剛完成 HIFU 或激光療程者（建議相隔一段時間再做）。
若你的皮膚問題明顯與月經週期同步波動（例如經前必爆痘），單靠外治效果有限，建議同時安排 {A:中醫婦科 -> /gynecology} 調理。

BODY SHAPING
[H2] 減肥修身：針灸、暖宮與茶療調理
中醫看肥胖不只計算熱量，而是先分辨脾虛、濕重、肝鬱與陽虛的體質差異。
同樣的飲食與運動，兩個人減出來的結果可以完全不同，原因在於體質。 {A:中醫減肥 -> /slim} 的第一步是辨證分型，找出「為甚麼你容易積聚」，再決定用針灸、中藥或茶療哪一組合為主。
[H3] 四種常見肥胖體質
|
| | 體質分型 | 身體訊號 | 脂肪分佈傾向 | 調理方向
| | 脾虛濕重 | 易疲倦、大便稀爛、下肢浮腫、舌苔厚白 | 下半身、小腿 | 健脾益氣、利水滲濕
| | 肝鬱氣滯 | 壓力大即想進食、經前乳脹、失眠、易怒 | 腰腹、側腰 | 疏肝理氣、調暢情志
| | 胃熱濕阻 | 食量大、口乾口氣、便秘、易生暗瘡 | 腹部為主 | 清胃泄熱、通腑導滯
| | 陽虛痰濕 | 怕冷、手腳冰冷、易水腫、代謝慢 | 全身鬆軟型 | 溫陽化氣、健脾化痰
[H3] 針灸減肥的原理與常用穴位
針灸減肥透過刺激穴位調節腦部飽覺與飢餓中樞，降低過度食慾，並改善脾胃運化與水濕代謝。常用方向包括飢點以調控食慾，脾俞、胃俞以改善消化吸收，天樞以疏調大腸、改善腹部積滯，配合腹針調整中焦運化。一般安排每週覆診一次、每週針灸一次，同時每日服用中藥調整體質，療程長度視目標與體質而定。
[H3] 腹部暖宮與女性腹部脂肪
不少女性腹部特別難減，同時伴隨經痛遇冷加劇、手腳冰冷、經血暗黑有塊——這類屬寒凝血瘀傾向。腹部暖宮療程配合中醫診症及中藥，方向是溫經散寒、促進局部氣血運行，同時改善經期不適。若你正在備孕或剛完成 {A:產後調理 -> /#gyne-detail} ，暖宮的安排與強度都需要另作調整。
[H3] 茶療減肥：做法與適用體質
茶療減肥 是日常輔助，不能取代辨證用藥。兩款常見保健配方僅供參考：
- 山楂決明消脂茶 ：山楂約 10 克、決明子約 10 克，以熱水沖泡焗約 15 分鐘。方向為消滯通腑，較適合胃熱濕阻、易便秘者。
- 荷葉薏米袪濕茶 ：荷葉、生熟薏米，方向為利濕消腫，較適合脾虛濕重、易水腫者。
要留意：決明子有通便作用，大便本已稀爛、脾胃虛寒、孕婦及經期量多者不宜；荷葉性偏涼，怕冷體質者不宜長期飲用。任何茶療都建議先諮詢註冊中醫師，並以「短期輔助」而非「長期日飲」的心態使用。
[H3] 穴位按摩與日常配合
自行按摩可在飯後約 2 至 3 小時進行，避開剛吃飽的時候，每個穴位打圈按摩約 3 分鐘。不過按摩屬輔助，真正決定成效的仍是睡眠、飲食結構與運動量三者。長期熬夜與高壓工作，會直接抵銷療程效果——這在觀塘一帶的上班族患者身上尤其常見。
[H3] 平台期與復胖預防
減重進入平台期，常見原因有三：熱量攝取長期過低導致代謝下調、睡眠不足影響荷爾蒙、以及水濕未化而體重數字停滯但體態仍在改善。處理方向是重新評估體質分型與飲食結構，而非單純加大節食力度。療程完成後建議進入維持期，以每月一次調理與茶療配合，鞏固易瘦體質。
體重管理沒有速成方案。任何承諾「一定減多少磅」的說法都不符合臨床現實；我們會在首次診症時說明合理預期與所需時間。

藍田診所設於匯景商場，服務藍田、油塘、康栢及鄰近屋苑居民。藍田以住宅為主，家庭客較多，因此 藍田中醫 診症中婦科與兒科相關詢問比例較高，包括備孕、安胎、產後調理與產後扎肚安排。 藍田美容 及 藍田減肥 療程亦適合產後媽媽在完成基礎調理後接續進行。

[H2] 中醫養生：香港人最需要的日常調理
治療處理已發生的問題，養生決定問題會否重複發生。
[H3] 四季養生的重點差異
香港氣候潮濕悶熱，加上長時間身處冷氣環境，形成「外濕內寒」的常見格局。春季重疏肝袪濕，夏季重清熱養心但避過度貪涼，秋季重養陰潤燥，冬季重補腎藏精。實際做法比理論重要：例如夏天不宜整天冷氣直吹加冷飲，這是香港女性宮寒與經痛加劇的常見成因之一。
[H3] 袪濕、睡眠與情緒三大基礎
- 袪濕 ：舌苔厚、身體沉重、大便黏爛、下肢浮腫，多屬濕重。改善以健脾為先，單靠喝袪濕茶效果有限。
- 睡眠 ：長期在凌晨後入睡，會直接影響肝血修復與內分泌，並拖慢 {A:中醫美容 -> /#beauty-detail} 與 {A:減肥修身 -> /#slim-detail} 療程的成效。
- 情緒 ：肝主疏泄，長期壓力會表現為經前乳脹、經期紊亂、脹氣與壓力型進食。
[H3] 體質自我觀察的三個指標
不需要專業工具，也能持續觀察自己的體質變化：一是 舌象 （舌體胖瘦、舌苔厚薄與顏色）；二是 大便 （成形與否、是否黏馬桶）；三是 經期 （週期、經量、色澤、痛感）。這三項連續記錄一至兩個月，會比任何主觀感覺更能反映調理進度，也能讓覆診時的判斷更精準。

FAQ
[H2] 常見問題
就診前最常被問到的問題，我們一次整理清楚。
[H3] 首次到觀塘或藍田診所診症，流程是怎樣？
首次診症約需 30 至 45 分鐘。醫師會先問診並望聞問切，了解你的主要不適、病史與生活作息，再說明體質判斷與建議方案，包括療程次數、預計時間與收費項目，之後才開始治療及配藥。女性患者請盡量帶備最近的月經記錄。
[H3] 需要預約嗎？可以即日到診嗎？
建議預約，可致電或 WhatsApp 5512 3132。星期一至六應診，上午 10:30–13:30、下午 14:30–19:30，星期日全日休診。即日到診視當日排程而定，預約可省卻輪候時間。
[H3] 美容針（美顏針）痛不痛？大約幾次見效？
使用極幼細的面部專用針具，近乎無痛，少數穴位可能有輕微酸脹感或出現細小出血點，絕大部分人可以接受。見效速度因人而異：浮腫與膚色暗沉類問題通常較早有感覺，紋路與輪廓鬆弛需要較長療程累積。臨床一般建議初期每週一次，之後轉為保養頻率。
[H3] 中藥面膜可以自己在家做嗎？
可以，但有兩個前提：藥粉來源可靠且研磨足夠細，以及配方要符合自己體質。乾性或敏感肌若使用大量清熱利濕藥材，容易越敷越乾。建議先在耳後試敷，並避開有傷口、活躍暗瘡感染，或正在使用果酸、A 酸的皮膚。
[H3] 中醫減肥會不會反彈復胖？
會否復胖，關鍵在療程結束後有否維持體質與生活習慣。中醫減肥的目標是調整脾胃運化與水濕代謝，若療程後回復熬夜、高糖高油飲食，體重自然反彈。我們一般建議完成主要療程後進入維持期，以較低頻率的調理配合飲食與運動鞏固成果。
[H3] 茶療減肥可以每日飲嗎？
不建議長期日飲。山楂決明類配方有通便作用，大便本已稀爛、脾胃虛寒、孕婦及經期量多者不宜；荷葉性偏涼，怕冷體質長期飲用可能加重手腳冰冷。茶療屬短期輔助，飲用前應先諮詢註冊中醫師。
[H3] 備孕期間看中醫，需要停止西醫療程嗎？
不需要自行停止。中醫調理屬輔助角色，可與 IVF／IUI 等生殖醫學療程配合，但必須讓中醫師知道你的完整用藥與療程時間表，以便避開衝突並調整處方時機。切勿在未諮詢主診醫生的情況下自行停藥。
[H3] 懷孕期間可以針灸嗎？
孕期針灸須由註冊中醫師評估後才進行，並嚴格避開禁針穴位。安胎用藥以補腎固胎、益氣養血、健脾和胃為主，避免行氣破血及大寒大熱之品。如有出血、腹痛或其他緊急情況，應立即前往急症或婦產科求診。
[H3] 產後扎肚甚麼時候開始最合適？
一般而言，順產媽媽可於產後約 4 星期、剖腹媽媽待傷口癒合約 6 至 8 星期後，經評估再開始。開始前應先檢查是否存在腹直肌分離；若腹壁中線空隙明顯，需先做針對性修復與盆底肌訓練。扎肚屬輔助手段，不能取代核心功能重建。
[H3] 產後多久可以開始減肥療程？
建議先完成產後基礎調理，恢復氣血與脾胃功能，一般在產後 8 週後、並在哺乳情況穩定的前提下，才安排針灸減肥等療程。哺乳期用藥需特別謹慎，請務必告知醫師你正在餵哺母乳。
[H3] 婦科癌症治療期間可以看中醫嗎？
可以作為輔助，用於減輕手術、化療、放療及內分泌治療帶來的疲倦、噁心、納差與關節痠痛等副作用。但中醫不可取代腫瘤科治療，且部分中藥與化療、標靶藥物存在相互作用，必須完整告知所有正在使用的藥物，並與主診醫生保持溝通。
[H3] 男士可以做面部經絡理療或針灸減肥嗎？
可以。中醫美容與減肥修身療程並不限性別，男士常見求診原因包括暗瘡、油脂分泌旺盛、應酬型腹部肥胖與代謝偏慢。診症流程與辨證方式相同，處方會按男性體質特點調整。
[H3] 中藥有沒有西藥的相互作用風險？
有。抗凝血藥、降糖藥、降血壓藥、免疫抑制劑與部分中藥可能產生相互作用。請於首次診症時列出所有正在服用的西藥、保健品與中成藥，並在治療期間有任何新增用藥時通知醫師。
[H3] 療程收費是否包括中藥？
收費會在開始前逐項列明，包括診金、針灸、理療及中藥。部分療程（例如針灸減肥、腹部暖宮）已連同中醫診症及中藥計算，具體以診症時說明為準。我們不會在療程中途追加未事先說明的費用。
以上內容為一般健康資訊，個別情況需經註冊中醫師面診後方能判斷。本網站不提供緊急醫療服務；如出現急性劇痛、大量出血、高燒或其他緊急症狀，請立即前往就近急症室。
