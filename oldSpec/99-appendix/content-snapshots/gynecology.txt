Traditional Chinese Medicine Gynecology
[H2] 中醫婦科
中醫婦科（Traditional Chinese Medicine Gynecology）是一門歷史悠久且非常完善的學科。中醫認為，女性的生理特點以「血」為本、以「氣」為用，且與腎、肝、脾三臟，以及衝、任、督、帶四脈的關係最為密切。
在中醫臨床中，婦科調理通常涵蓋五大核心領域。聖儀堂由註冊中醫潘巧儀醫師主理（廣州中醫藥大學婦科博士研究生、香港大學臨床婦科學深造課程），專業婦科醫師，以辨證論治為每位女士度身施治。
由 女醫師 主理婦科的實際好處是：描述經期、白帶、性生活、備孕與產後問題時，患者通常較願意講得完整。而婦科辨證最依賴的正是這些細節——資料不完整，辨證就會失準。

中醫婦科不是「調經」兩個字可以概括。它按女性生命階段展開：青春期的初潮與經期紊亂、生育年齡的備孕與孕產、產後的氣血重建、以及圍絕經期的陰陽調節。每個階段的用藥方向都不同，甚至同一位患者在不同階段需要完全相反的處理。

GYNECOLOGY
[H2] 婦科五大核心領域
在中醫臨床中，婦科調理通常涵蓋以下五大核心領域：
01
[H3] 月經調理（經）
這是中醫婦科最常見的就診原因。中醫不只看月經週期，還會結合月經的期（週期）、量、色、質以及伴隨症狀來綜合辨證。
常見調理： 月經後期（推遲）、月經先期（提早）、痛經、閉經、崩漏（功能性子宮出血）以及經前綜合徵（PMS）。
[H4] 為何四項要素要一起看
單看週期長短資訊有限。例如同樣是「經期延後」，若經量少而色淡、經後疲倦，多屬氣血不足；若經量少但色暗有塊、經前乳脹，則多屬肝鬱兼血瘦。前者要補、後者要疏，方向剛好相反——這就是為何醫師會問得比你預期的多。
02
[H3] 帶下調理（帶）
主要指陰道分泌物的異常。中醫主要從「濕邪」入手，認為帶下異常多因脾虛失運、腎氣不固或下焦濕熱所致。
常見調理： 白帶過多、色黃、質稠、有異味或伴隨外陰瘙癢等。
[H4] 甚麼情況應先做西醫檢查
如出現分泌物明顯異味、顏色異常（黃綠、灰白）、伴隨明顯灼痛或性交後出血，建議先進行婦科檢查與化驗，以排除感染性疾病。中醫調理可作後續體質支援，但不應延誤必要的檢驗與治療。
03
[H3] 胎產與孕前準備（胎／產）
中醫在助孕和產後調養方面有獨特的優勢，強調「種子必先調經」。
- 孕前調理： 改善子宮內膜環境、提升卵子質素，為懷孕打下基礎。
- 保胎安胎： 針對有先兆流產跡象或習慣性流產史的女性，以益氣養血、固腎安胎為方向。
- 產後調理： 所謂「產後多虛多瘀」，著重惡露排除、催乳、產後關節痛（產後風）以及氣血體質的恢復。
04
[H3] 不孕症與生殖調理
中醫常將不孕症分為腎虛、肝鬱、痰濕、血瘀等不同證型，透過中藥和針灸來調節內分泌、促進排卵，現時亦常與現代醫學的試管嬰兒（IVF）療程配合，例如取卵前調理與移植後安胎。
[H4] 不孕從來不是單方面的問題
精液質素、活動力與形態同樣是關鍵。若備孕超過一年未成功，建議夫婦雙方同步檢查與調理，而非只由女方單方面處理。
05
[H3] 更年期與婦科雜病
- 更年期綜合徵： 圍絕經期因腎氣漸衰、天癸將竭，常出現潮熱盜汗、失眠多夢、情緒波動等，中醫以滋陰清熱、調理陰陽為主。
- 雜病： 子宮肌瘤、卵巢囊腫、多囊卵巢綜合徵（PCOS）、盆腔炎、子宮內膜異位症等。
[H3] 中醫婦科的核心原則
「急則治其標，緩則治其本。」在經期通常以袪瘀、止痛、調經為主；在非經期則以調理臟腑、滋養氣血為主。這也是為何婦科處方經常需要按週期調整，而不是一條方吃到底。

MENSTRUAL HEALTH
[H2] 月經失調的辨證分型
月經是女性體質最直接的成績表，也是療效最可靠的觀察窗口。
|
| | 常見分型 | 典型表現 | 調理方向
| | 氣血兩虛 | 經量少而色淡、經後疲倦、頭暈心悸、面色蒼白、易脫髮 | 益氣養血、健脾生血
| | 肝鬱氣滯 | 經前乳房脹痛、情緒煩躁、經期不定、血塊較多、經前失眠 | 疏肝解鬱、理氣活血
| | 寒凝血瘀（宮寒） | 經痛遇冷加劇、熱敷後舒緩、血色暗黑有塊、手腳冰冷、下腹偏涼 | 溫經散寒、活血化瘀
| | 濕熱下注 | 白帶量多色黃、下陰痕癢、口苦、經期延長、小便偏黃 | 清熱利濕、調理衝任
| | 腎虛 | 經量漸少或週期延長、腰膝痠軟、耳鳴、夜尿、性慾減退 | 補腎填精、調養衝任
[H3] 如何記錄月經，令診症更準確
用手機記錄即可，重點是連續三次以上，包括五項：
- 日期 ：每次來經第一日與結束日（可推算週期長短）。
- 經量 ：以每日用量估計（衛生巾數量與飽和程度）。
- 經色 ：鮮紅、暗紅、暗黑、淡紅。
- 血塊 ：有無、大小、多少。
- 痛感 ：出現時機（經前／經第一日／經期後段）、位置、遇冷或遇熱的變化。
這五項的變化趨勢，比「感覺好些了」準確得多，也是判斷處方是否需要調整的主要依據。
[H3] 痛經：分辨「該補」還是「該通」
痛經不是一種病，而是多種病機的共同表現。臨床上最實用的分辨方法是觀察痛感與時機的關係：經前及經第一二日劇痛、血塊排出後舒緩，多屬瘀滯，方向為活血通瘀；經期後段或經後隱隱作痛、按之舒服，多屬氣血不足，方向為補益。若熱敷明顯舒緩，多有寒證成分，可考慮配合 {A:腹部暖宮 -> /slim#womb} 。
[H3] 經前綜合徵（PMS）的處理
經前乳脹、情緒起伏、頭痛、腹脹、暴食傾向，多與肝鬱氣滯相關。處理上除疏肝理氣外，睡眠與壓力管理同樣關鍵——臨床上經常見到，工作旺季的 PMS 明顯較平時嚴重。若同時出現經前必爆的暗瘡，可與 {A:中醫美容 -> /beauty} 療程一併規劃。
[H3] 為何調理要跟三個月經週期
單看一次經期，難以分辨是偶發波動還是體質問題。連續觀察三個週期，變化趨勢才會清楚呈現。因此我們一般以三個週期為一個評估單位，中途按進展調整處方。
⚠️ 以下情況請先就醫檢查，不要單靠調理
經量突然大幅增加或持續出血超過十天、非經期出血、性交後出血、停經後出血、劇烈腹痛伴發燒或暈眩、閉經超過三個月且已排除懷孕。這些情況需要婦科檢查與影像／化驗確認病因，中醫調理應在明確診斷後才作輔助。
<!-- 不孕不育 -->
FERTILITY
[H2] 婦女不孕不育的中醫調理
核心方法是「分階段用藥」——順着月經週期的生理節奏調整處方。
[H3] 按月經週期分四階段用藥
|
| | 階段 | 生理重點 | 中醫調理方向
| | 經期 | 子宮內膜剝落排出 | 理氣活血，促使排出通暢
| | 經後期（濾泡期） | 卵子發育、內膜修復 | 養血滋陰，滋養卵子與內膜
| | 排卵期 | 排卵 | 疏肝活血，助排卵通暢
| | 經前期（黃體期） | 黃體支持、準備著床 | 補腎助陽，穩固黃體功能
這種按週期節奏調整處方的做法，比長期服用同一條方更貼合生理變化。也因此，備孕調理的覆診時間通常會配合週期安排，而非固定每月同一日。
[H3] 常見求診情況
- 月經稀少、週期過長或閉經。
- 多囊卵巢傾向、排卵不規律。
- 黃體功能不足、基礎體溫高溫期偏短。
- 輸卵管術後、輸卵管通暢度欠佳。
- 卵巢儲備下降、高齡生育。
- 反覆早期流產、復發性流產。
- 子宮內膜偏薄、內膜環境欠佳。
[H3] 男方同步調理同樣重要
精液質素、活動力與形態，中醫可從補腎益精、清利濕熱等方向調理。臨床上常見的可改善因素包括長期熬夜、吸煙飲酒、長時間高溫環境（如經常泡熱水浴、久坐）與壓力。建議夫婦同步檢查與調理，時間效率會高得多。
[H3] 備孕期間的生活調整
- 睡眠 ：盡量在晚上十一時前入睡，這對內分泌節律影響最直接。
- 體重 ：過重與過輕都會影響排卵，體重管理可與 {A:減肥修身 -> /slim} 療程配合，但備孕期間不宜激烈減重。
- 避免過度生冷 ：長期冷飲與凍食會削弱脾胃運化，對寒證體質尤其不利。
- 減少壓力來源 ：焦慮本身會影響排卵與週期，「越急越不來」是臨床常見現象。
中醫調理屬輔助性質，不能取代生殖醫學檢查與治療。若備孕超過一年（35 歲以上超過半年）仍未成功，建議同步進行西醫生殖科評估，包括荷爾蒙檢查、超聲波、輸卵管通暢度及男方精液分析。
<!-- IVF/IUI -->
ART SUPPORT
[H2] 配合 IVF／IUI 的中醫調理
中醫在人工受孕流程中的角色是「配合」，時序比藥味更重要。
[H3] 取卵前：改善卵子質素與內膜環境
此階段以益氣養血、滋陰為主，目標是改善子宮血流與內膜環境，並支持卵泡發育。一般建議在進入療程前預留至少二至三個月調理時間，因為卵子的發育週期本身需要時間，臨到取卵前才開始，可調整的空間有限。
[H3] 移植後：補腎固衝，穩定著床
移植後調理重點轉向「補腎、益氣、養血」。透過補腎固衝的方向，降低子宮敏感度與收縮頻率，營造較安靜的環境讓胚胎著床。此階段用藥須格外謹慎，避免行氣破血之品。
[H3] 心理疏導同樣是治療的一部分
人工受孕過程的心理壓力極大，等待驗孕結果的日子尤其難熬。焦慮會影響睡眠與內分泌，形成惡性循環。診症時我們會預留時間讓患者表達，這不是閒聊——情緒狀態本身就是辨證資料，也直接影響肝的疏泄功能。
[H3] 反覆流產的調理思路
復發性流產需要先由西醫查找原因（染色體、免疫、內分泌、子宮結構、凝血因素等）。中醫的角色是在明確方向後，以補腎固胎、益氣養血支持體質，並在下次懷孕前預留足夠恢復時間。連續流產後立即再次懷孕，母體氣血未復，風險較高。
[H3] 必須告知醫師的資料
- 正在使用的所有促排卵藥、荷爾蒙針劑與口服藥物及劑量。
- 療程時間表：預計取卵日、移植日、驗孕日。
- 過往療程次數與結果。
- 是否有卵巢過度刺激（OHSS）病史。
部分中藥與促排卵藥物、荷爾蒙製劑可能相互影響，時序安排錯誤有機會干擾療程。請勿在未告知的情況下自行加服任何中藥或補品。
中醫調理不可取代生殖醫學治療，亦不應延誤既定的 IVF／IUI 排程。任何中醫用藥安排都應與你的生殖科主診醫生保持資訊同步。

PREGNANCY CARE
[H2] 懷孕安胎與孕期不適
安胎用藥的原則只有一個字：穩。
[H3] 安胎的用藥原則
以補腎固胎、益氣養血、健脾和胃為主，避免行氣破血與大寒大熱之品。孕期用藥的考量與平時完全不同：即使某味藥對母體的某個症狀有效，若屬妊娠禁忌或慎用之品，一律不用。這也是孕期絕不應自行服用任何中藥或補品的原因。
[H3] 孕期常見不適的中醫處理
|
| | 不適 | 常見時期 | 調理方向
| | 妊娠嘔吐、胃脹納差 | 孕早期 | 健脾和胃、降逆止嘔
| | 疲倦乏力、頭暈 | 孕早期至中期 | 益氣養血
| | 便秘 | 孕中期至後期 | 養血潤燥（避免瀉下藥）
| | 腰痠、腿腫 | 孕中期至後期 | 補腎健脾、利水（力度須溫和）
| | 失眠、心煩 | 各期 | 養心安神、清心除煩
| | 感冒咳嗽 | 各期 | 疏解外邪，嚴格避開孕期禁忌藥
[H3] 孕期針灸的界線
孕期針灸須由註冊中醫師評估後才進行，並嚴格避開禁針穴位。並非所有孕婦都適合，尤其是有先兆流產跡象、前置胎盤或其他高危因素者。若你正在接受產科的特別監察，請於診症時完整說明。
[H3] 清胎毒的正確理解與時機
民間所謂「清胎毒」，中醫理解為孕晚期清理母體濕熱。一般在懷孕約 32 週後、並由中醫師確認體質確實屬濕熱者才考慮， 並非人人適合，也非必做項目 。體質偏虛寒者盲目清熱，反而可能損傷脾胃、加重疲倦。坊間流傳的固定食譜不分體質使用，風險較高。
[H3] 孕期飲食的實用原則
不需要「大補」。孕期營養重點在均衡與可吸收，過度進補反而容易造成胃脹納差與體重增加過快。避免生冷、酒類與過度燥熱的食物；若有妊娠糖尿或高血壓，飲食安排須以產科建議為主。
⚠️ 孕期出現以下情況，請立即前往急症室或產科
陰道出血、持續或劇烈腹痛、破水、胎動明顯減少或消失、劇烈頭痛伴視力模糊、持續嘔吐無法進食進水、發燒。中醫診所不提供緊急產科服務，切勿延誤。

POSTNATAL CARE
[H2] 產後調理與產後扎肚
「產後多虛多瘀」——先復氣血，再談體態。
[H3] 產後四階段的調理重點
|
| | 階段 | 調理重點 | 常見處理
| | 產後 0–2 週 | 排出惡露、健脾和胃 | 溫和活血化瘀、飲食調整、充分休息
| | 產後 2–4 週 | 益氣養血、通乳 | 中藥調理、乳少或塞奶處理
| | 產後 4–8 週 | 評估腹直肌分離與子宮復原 | 呼吸、盆底肌與腹橫肌啟動訓練；順產者可評估開始扎肚
| | 產後 8 週後 | 體態重建與體重管理 | {A:針灸減肥 -> /slim} 、腹部暖宮（哺乳穩定前提下）
[H3] 常見產後問題
- 惡露不止或排出不暢 ：方向為活血化瘀兼益氣，須先排除胎盤殘留等問題。
- 乳少或塞奶 ：乳少多屬氣血不足或肝鬱，塞奶則須同時處理排乳與局部通絡。
- 產後關節痛（產後風） ：多屬氣血虛加風寒濕，方向為益氣養血、溫通經絡。
- 產後腰痛、排尿不暢 ：與腎氣不足及骨盆底功能相關。
- 產後脫髮 ：多屬氣血兩虛，一般隨體質恢復而改善。
- 情緒低落 ：若持續、影響日常功能或有傷害念頭，須立即尋求精神科或臨床心理專業支援。
[H3] 產後大肚腩的三個原因
坐月後的大肚腩未必只是脂肪，通常涉及三方面： 腹直肌分離 （腹壁中線空隙擴大）、 子宮復原進度 （子宮尚未回復正常體積）、以及 氣血不足與水液代謝 。因此處理次序應為先評估、再修復功能、最後才是體態塑形。
[H3] 產後扎肚是甚麼、原理為何
產後扎肚是透過特定按摩手法配合紮身帶，促進血氣運行與新陳代謝，幫助排出水腫、肚風及宿便，令子宮加速回復正常體積，並減低鄰近器官所承受的壓力。坊間常見的流派包括馬來西亞古法、印尼古法等，手法與紮法各異。
[H4] 開始扎肚的安全時機
- 順產 ：一般在產後約 4 星期後，經評估再開始。
- 剖腹 ：待傷口癒合，一般約 6 至 8 星期後，並確認傷口無異常。
- 須先評估的情況 ：腹壁中線空隙明顯、有腹壁疝、傷口癒合不良、產後出血未穩定。
[H4] 扎肚的限制：三件它做不到的事
- 不能取代腹直肌修復 。若中線空隙明顯，應先做針對性修復訓練。
- 不能取代盆底肌訓練 。漏尿、下墜感等問題需要專門的盆底肌復健。
- 不能替代氣血調理 。若媽媽本身怕凍、疲倦、頭暈、胃口差、便秘或腰痠，應先處理整體復原狀態，而非急於收細肚圍。
[H3] 中醫產後修復的正確次序
- 辨明體質與所處產後階段。
- 調理氣血、脾胃與水濕代謝。
- 由溫和核心訓練開始：呼吸、骨盆底、腹橫肌啟動，不宜過早做高強度捲腹。
- 再考慮腹帶或扎肚作為輔助手段。
- 最後才進入體重管理階段。
次序倒轉是產後最常見的錯誤——修復速度會因休息不足與長期壓力而變慢，急於求成往往兩邊都做不好。
[H3] 哺乳期用藥注意
哺乳期用藥須特別謹慎，部分活血、行氣、通便藥材不宜使用，亦要避開影響泌乳的藥材。請於診症時告知餵哺母乳的情況與頻率，以及是否同時使用泵奶。
<!-- 更年期 -->
MENOPAUSE
[H2] 更年期綜合症調理
這不是「忍幾年就過去」的階段，而是值得認真調理的過渡期。
[H3] 常見表現與中醫理解
潮熱、盜汗、失眠、心悸、情緒起伏、記憶力下降、陰道乾澀、關節痠痛，中醫多歸於腎陰漸虧、肝陽偏亢、心腎不交。調理方向以滋腎養陰、平肝安神為主，並同步處理睡眠與情緒——因為兩者互為因果，睡不好會加重潮熱，潮熱又令人睡不好。
[H3] 調理的三個層次
- 症狀層 ：先減輕最影響生活的一至兩項（多數是失眠與潮熱）。
- 體質層 ：滋養腎陰、調和肝脾，減少症狀反覆。
- 預防層 ：此階段是骨質、代謝與心血管風險變化的關鍵期，適合把養生習慣正式建立起來。
[H3] 與荷爾蒙補充治療（HRT）的關係
兩者不必對立。若你正在接受或考慮 HRT，請告知醫師，我們會據此調整中藥方向與時序。是否使用 HRT 屬西醫的臨床決定，應與婦科醫生討論，中醫不會建議你自行停用。
[H3] 日常可做的四件事
規律睡眠時間比睡眠時數更重要；適量負重運動有助骨質；減少咖啡、酒精與辛辣（這些是潮熱的常見誘發因素）；以及建立非進食的減壓方式。這部分的整體建議，可參閱 {A:中醫養生 -> /#wellness} 一節。
停經後如出現陰道出血，屬需要即時檢查的警示症狀，請盡快就診婦科，不應以「更年期正常現象」看待。

DISORDERS
[H2] 常見婦科雜病
中醫的角色是體質支援與症狀改善，不能取代必要的檢查與手術評估。
[H3] 子宮肌瘤
中醫多從氣滯血瘀、痰濕結聚方向理解。調理目標主要是改善伴隨症狀（經量過多、經痛、腹脹壓迫感）與體質狀態，而非承諾令肌瘤消失。肌瘤的大小、位置與生長速度需要定期超聲波監察；若出現壓迫症狀、經量過多致貧血或短期內明顯增大，須由婦科醫生評估是否需要手術。
[H3] 卵巢囊腫
需先由影像檢查區分性質（功能性囊腫、內膜異位性囊腫等）。功能性囊腫有機會自行消退，中醫可從理氣化痰、活血散結方向支援；但任何持續增大、性質不明或伴隨劇痛的囊腫，都必須由婦科跟進，並警惕扭轉等急性情況。
[H3] 多囊卵巢綜合徵（PCOS）
臨床上常見表現包括月經稀少或閉經、排卵不規律、體重上升困難減、多毛或暗瘡。中醫多從腎虛兼痰濕、肝鬱方向處理，調理方向為補腎、化痰濕、疏肝。體重與代謝管理是關鍵一環，可與 {A:減肥修身 -> /slim} 配合；若同時有明顯暗瘡與油脂問題，可加入 {A:中醫美容 -> /beauty} 調理。
[H3] 子宮內膜異位症
典型表現為漸進加重的經痛、經期腸胃不適、性交疼痛，部分伴不孕。中醫多從寒凝血瘀、氣滯血瘀方向處理，重點在改善經痛與體質。此病屬需長期管理的疾病，建議中西醫並行，並定期由婦科評估。
[H3] 盆腔炎與反覆泌尿道感染
急性感染須以西醫抗生素治療為主，中醫可在急性期過後從清熱利濕、益氣扶正方向減少反覆。若出現發燒、劇痛或分泌物異常，應先就醫檢驗。
[H3] 乳腺增生
多與肝鬱氣滯、衝任失調相關，常隨情緒與經期波動。調理方向為疏肝理氣、活血散結。任何新出現的乳房硬塊、單側乳頭溢液或皮膚凹陷，必須先做乳房影像檢查。
⚠️ 重要原則
以上所有情況，中醫調理均屬輔助角色，不能取代影像檢查、化驗與婦科／外科的專業評估。任何聲稱可以「消除肌瘤」「化掉囊腫」的說法，都不符合臨床現實。定期覆檢是最基本的保障。

BEFORE YOUR VISIT
[H2] 婦科診症前的準備
準備得越完整，首次診症能處理的就越多。
[H3] 建議帶備的資料
- 月經記錄 ：最近三次的日期、經量、經色、血塊與痛感（手機記錄即可）。
- 檢查報告 ：荷爾蒙檢查、超聲波、子宮頸細胞檢查、輸卵管檢查、甲狀腺功能等。
- 用藥清單 ：所有西藥、中成藥、保健品與補充劑，包括避孕藥與荷爾蒙製劑。
- 生育史 ：懷孕次數、生產方式、流產史、人工受孕療程記錄。
- 過敏史 ：藥物、食物、膠布或消毒用品。
- 基礎體溫記錄 ：如有量度，備孕患者尤其有用。
[H3] 診症當日的注意事項
不要刮舌苔，避免咖啡、紅酒、火龍果汁等會染色舌面的飲品；避免空腹過久或剛吃飽即到診；經期期間亦可診症，部分情況更適合在經期觀察脈象與症狀，只需預約時說明即可。
[H3] 首次診症流程
約需 30 至 45 分鐘：登記與健康問卷、四診辨證（望聞問切）、說明體質判斷與建議方案、列明收費項目、治療及配藥、安排覆診。婦科調理的覆診時間通常會配合月經週期安排，而非固定每月同一日。
[H3] 覆診節奏與記錄建議
一般安排每週或每兩週覆診，並以三個月經週期為一個評估單位。建議持續記錄三項指標：舌象、大便情況與月經狀況。這些客觀記錄比主觀感覺可靠，也讓處方調整更精準。完整的到診須知可參閱 {A:首次到診須知 -> /about#first-visit} ，收費安排請見 {A:收費一覽 -> /services#price} 。

FAQ
[H2] 中醫婦科常見問題
婦科求診前最常被問到的 16 個問題。
[H3] 婦科診症是由女醫師負責嗎？
是。婦科、產後及中醫美容相關療程由主理醫師潘巧儀（女性註冊中醫）處理。她為廣州中醫藥大學婦科博士研究生，並完成香港大學臨床婦科學深造課程。預約時可直接說明希望由女醫師診症。
[H3] 婦科調理一般需要多久才見到變化？
一般以三個月經週期為一個評估單位。月經是最直接的觀察窗口——經量、經色、血塊與痛感的變化趨勢，比主觀感覺更能反映進度。中途醫師會按進展調整處方，而非固定一條方吃到底。
[H3] 經期可以看中醫、可以服中藥嗎？
可以，而且部分情況更適合在經期診症，因為經期本身就是重要的觀察窗口。用藥方向會按經期調整：經期一般以理氣活血、通暢排出為主，非經期則以調理臟腑、滋養氣血為主。
[H3] 經期可以針灸嗎？
須由醫師評估。經期期間部分穴位與手法會避開。若經量較多或經痛嚴重，建議將針灸安排在經期以外的日子，並於預約時告知經期日期。
[H3] 備孕期間看中醫，需要停止西醫療程嗎？
不需要自行停止。中醫調理屬輔助角色，可與 IVF／IUI 等生殖醫學療程配合，但必須讓中醫師知道你的完整用藥與療程時間表（預計取卵日、移植日、驗孕日），以便避開衝突並調整處方時機。切勿在未諮詢主診醫生下自行停藥。
[H3] 準備做 IVF，應該提前多久開始中醫調理？
建議在進入療程前預留至少二至三個月。卵子的發育週期本身需要時間，臨到取卵前才開始，可調整的空間有限。取卵前以益氣養血、滋陰改善內膜環境為主；移植後轉向補腎固衝、益氣養血。
[H3] 備孕多久未成功才需要求診？
一般建議：35 歲以下夫婦正常性生活一年未成功，35 歲以上半年未成功，就應同步進行西醫生殖科評估（荷爾蒙檢查、超聲波、輸卵管通暢度及男方精液分析），並可配合中醫調理。
[H3] 不孕是否只需要女方調理？
不是。精液質素、活動力與形態同樣關鍵，中醫可從補腎益精、清利濕熱方向處理男方問題。建議夫婦同步檢查與調理，時間效率會高得多。
[H3] 懷孕期間可以針灸和服中藥嗎？
可以，但必須由註冊中醫師評估後進行。孕期針灸須嚴格避開禁針穴位，並非所有孕婦都適合（如有先兆流產跡象、前置胎盤者須格外謹慎）。安胎用藥以補腎固胎、益氣養血、健脾和胃為主，避免行氣破血及大寒大熱之品。切勿自行服用任何中藥或補品。
[H3] 清胎毒是必須做的嗎？甚麼時候做？
不是必做項目。中醫理解為孕晚期清理母體濕熱，一般在懷孕約 32 週後、並由中醫師確認體質確實屬濕熱者才考慮。體質偏虛寒者盲目清熱，可能損傷脾胃、加重疲倦。坊間流傳的固定食譜不分體質使用，風險較高。
[H3] 坐月期間可以看中醫嗎？甚麼時候開始調理？
可以。產後 0 至 2 週以排出惡露、健脾和胃為重點；2 至 4 週轉向益氣養血與通乳。若有惡露不止、乳少、塞奶、產後腰痛或關節痛，都可在此階段處理。哺乳期用藥須特別謹慎，請告知餵哺情況。
[H3] 產後扎肚甚麼時候開始最合適？
順產媽媽一般在產後約 4 星期後，剖腹媽媽待傷口癒合約 6 至 8 星期後，經評估再開始。開始前應先檢查是否存在腹直肌分離；若腹壁中線空隙明顯，需先做針對性修復與盆底肌訓練。扎肚屬輔助手段，不能取代核心功能重建。
[H3] 產後大肚腩是不是只要扎肚就可以？
未必。產後大肚腩通常涉及三方面：腹直肌分離、子宮復原進度，以及氣血不足與水液代謝。若媽媽本身怕凍、疲倦、頭暈、胃口差、便秘或腰痠，應先處理整體復原狀態，而非急於收細肚圍。正確次序是先評估、再修復功能、最後才塑形。
[H3] 中醫可以令子宮肌瘤或卵巢囊腫消失嗎？
不能作此承諾。中醫調理目標是改善伴隨症狀（經量過多、經痛、腹脹壓迫感）與整體體質。肌瘤與囊腫的大小、位置與性質需要定期影像檢查監察；若出現壓迫症狀、經量過多致貧血或短期內明顯增大，須由婦科醫生評估。
[H3] 更年期正在做荷爾蒙補充治療，可以同時看中醫嗎？
可以。請告知醫師你正在使用的荷爾蒙製劑與劑量，我們會據此調整中藥方向與時序。是否使用 HRT 屬西醫的臨床決定，應與婦科醫生討論，中醫不會建議你自行停用。
[H3] 婦科癌症治療期間可以看中醫嗎？
可以作為輔助，用於減輕手術、化療、放療及內分泌治療的副作用，如疲倦、噁心納差、白細胞偏低、口乾與關節痠痛。但中醫不可取代腫瘤科治療，且部分中藥與化療、標靶或內分泌藥物存在相互作用，必須完整告知所有用藥並與主診醫生保持溝通。
